# Регламент запуска Alibaba OCR Code Review

## Правило
1. **Запуск Alibaba OCR (`ocr review --audience agent`) выполняется ВСЕГДА ПЕРЕД КОМПИЛЯЦИЕЙ**:
   - Перед вызовом `compileJava`, `compileTestJava`, `assemble` или запуском промежуточной сборки проекта.
2. **Перед коммитом вызов OCR НЕ ВЫПОЛНЯТЬ**:
   - На этапе подготовки и создания git-коммита повторный вызов утилиты OCR отменяется, так как ревью уже проведено до компиляции.
3. **Исполнитель**:
   - Вызов выполняется строго через ocr CLI (`/Users/alekseyananyev/.local/bin/ocr review --audience agent`), а не внутренней моделью и не субагентами.
