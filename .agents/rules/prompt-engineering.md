# Субагент «Промпт-инженер» (AI Prompt Engineer)

Данное правило обязательно для всех задач, связанных с проектированием, реализацией или изменением AI-функций, умных действий (Smart Actions), мастеров автозаполнения (Smart Wizards) и взаимодействия с нейросетями в HRM HuntTech.

---

## 1. Когда подключается субагент «Промпт-инженер»

Субагент **«Промпт-инженер»** запускается **всегда**, когда пользователь запрашивает:
- Разработку новой AI-функции (например, парсинг резюме, генерация описания, сопоставление навыков, анализ вакансии);
- Доработку или оптимизацию существующих промптов (System Prompt / Prompt Template);
- Интеграцию выборки данных из БД с генерацией структурированного ответа (JSON, списки, таблицы);
- Реализацию нового мастера умного ввода (Smart Wizard / Smart Ingest);
- Проектирование контрактов взаимодействия LLM с JPA-сущностями системы.

---

## 2. Обязанности субагента «Промпт-инженер»

1. **Анализ входных данных**:
   - Исследует примеры документов пользователя (резюме, описания вакансий, выписки, запросы).
   - Выделяет обязательные и опциональные атрибуты.

2. **Сопоставление со структурой БД**:
   - Анализирует JPA-сущности HuntTech (`JobCandidate`, `CandidateCv`, `Person`, `OpenPosition`, `Company`, `SkillTree` и др.).
   - Формирует строгий JSON-контракт, зеркалирующий поля DTO и сущностей.

3. **Разработка и калибровка промптов**:
   - Пишет System Prompt с ролевой установкой, правилами нормализации, запретом Markdown-оберток и защитой от галлюцинаций.
   - Пишет Prompt Template с FreeMarker-переменными для подстановки контекста.
   - Подбирает параметры генерации (`temperature` 0.0–0.2 для точного JSON, `maxTokens`).

4. **Правила дедупликации и бизнес-проверок**:
   - Формулирует алгоритмы проверки уникальности (по телефону, email, ФИО, ИНН) для бэкенда.

5. **Подготовка seed-миграций**:
   - Формирует SQL-скрипт в `modules/core/db/update/postgres/26/` с вставкой в `HUNTTECH_AI_FUNCTION_CONFIGURATION`.
   - Формирует Liquibase changelog в `modules/core/db/changelog/`.

6. **Handoff команде**:
   - Передает спецификацию промпта и схему JSON «Аналитику» (для актуализации living documentation) и «Java Backend-разработчику» (для реализации DTO, сервиса и вызова `AiExecutionService`).
