## Исходная мысль руководителя

> надо сделать API чтобы была возможность создания вакансии внешними приложениями.
> Надо создавать проект, вакансию.
> давай доработаем API интеграцию: 
> 1. надо найти город для которого ищется вакансия и установить в поле город. Если это удаленка, то выставляется из справочника Города "Регионы РФ (МСК+-2 часа)"
> 2. Оформление - аусттавфинг, если не указано иное
> 3. ставка ставится - ставка заказчика и рассчитывается зарплатное предложение исходя из справочника "Рейты по аутстафу". Если точного значения не найдется, то устанавливается ближайшее в меньшую сторону. Если ставки заказчика найти не удалось, то устанавливается флаг "Ориентируемся на запрос кандидата". 
> 4. Алгоритм определения рекрутинг или аутстафинг: если указано четкое зарплатное предложение, например "15000 рублей", то это рекрутинг. Если ставка в час, то это аутстафинг.
> 5. Автор записи - "hunttech"
> 6. Если в резюме есть что-то типа "резюме принимаются до ..." то выставляется эта дата в поле "Дата закрытия"
> 7. общий опыт работы по специальности выставляется путем определения требований в самом резюме, если этого нет исходя из принципа: junior - 2 года, middle/regular - 3 года, senior/lead/architect - от 5 лет
> 8. В поле "Английское описание вакансии" вставляется AI перевод русского описания вакансии.
> ГЛАВНОЕ - поле "вакансия". Оно формируется следующим образом. После заполнения всех полей, вызывается алгоритм, который прикреплен к кнопке "Генерировать" во вкладке "Вакансия" форма OpenPositionEdit.

## Реализованный результат

Метод `POST /hrm/rest/v2/services/hunttech_ExternalIntegrationService/createProjectAndVacancy` полностью реализован и запущен в промышленную эксплуатацию:
1. **Атомарность и безопасность**: проект (`Project`) и вакансия (`OpenPosition`) создаются в единой транзакции под контролем идемпотентности (`idempotencyKey`).
2. **Город**: для удаленного формата автоматически устанавливается канонический город «Регионы РФ (МСК +/- 2 часа)» из справочника `hunttech_City`.
3. **Оформление**: по умолчанию Аутстаффинг (`0`), при окладе в месяц — Рекрутинг (`1`).
4. **Рейты**: ставка пишется в `outstaffingCost`, вилки зарплаты рассчитываются по справочнику `hunttech_OutstaffingRates` (по совпадению или ближайшему меньшему). При отсутствии ставки выставляется флаг `salaryCandidateRequest = true` («Ориентируемся на запрос кандидата»).
5. **Автор записи**: системный пользователь `hunttech` (`ExtUser`).
6. **Дата закрытия**: парсинг дедлайнов подачи резюме в дату `closingDate`.
7. **Опыт работы**: определение из текста, либо по грейду (junior=2, middle=3, senior/lead/architect=5 лет).
8. **Английское описание**: AI перевод структурированного описания на английский язык (`commentEn`) в формате валидного HTML.
9. **Каноническое название вакансии**: поле `vacansyName` формируется по алгоритму кнопки «Генерировать» формы `OpenPositionEdit`.
10. **AI-артефакты**: автоматическая генерация чеклиста, карты поиска, плана собеседования, описания вакансии и проекта в чистом HTML.
