> **Дата составления:** 2026-09-12  
> **Роли:** Аналитик, UI/UX-дизайнер, Java Backend-разработчик, Frontend-разработчик  
> **Область:** Дашборды AI (`hunttech_UserAiDashboard`, `hunttech_AdminAiDashboard`), Редактор пользователя (`hunttech_ExtUser.edit` / `ExtUserEditor`), сервисы квот (`LlmChatServiceBean`, `AiExecutionService`)  

---

## 1. Бизнес-цели и требования

1. **Личный дашборд пользователя (`hunttech_UserAiDashboard`)**:
   - Пользователь должен видеть полную прозрачность своих затрат:
     - Выделенная администратором квота токенов на текущий месяц.
     - Фактически использованные токены за текущий месяц.
     - Текущий остаток доступных токенов с цветовой индикацией.
2. **Административный дашборд (`hunttech_AdminAiDashboard`)**:
   - Руководство и администраторы должны иметь сводную таблицу по **всем активным пользователям** (`active = true`):
     - ФИО и логин сотрудника.
     - Выделенный лимит токенов (персональный override или системная квота по умолчанию).
     - Использовано токенов в текущем месяце.
     - Текущий остаток токенов и процент расхода.
     - Общее число вызовов AI и суммарная стоимость в USD.
     - Дата последнего обращения.
3. **Карточка пользователя (`ExtUserEditor` / `ext-user-edit.xml`)**:
   - Во вкладке «Настройки AI» добавить блок управления лимитами корпоративных моделей:
     - Поле редактирования месячной квоты токенов администратором.
     - Информационные поля: расход токенов в текущем месяце и текущий остаток.
     - Сохранение персонального переопределения (`LlmUserQuotaOverride`) и обновление расчетного периода (`LlmChatQuotaPeriod`).

---

## 2. Модель данных и источники правды

1. **Системная квота по умолчанию**:
   - `AiFunctionConfiguration` (`code = 'LLM_CHAT'`) -> поле `defaultMonthlyTokenQuota` (по умолчанию 500 000 токенов, либо -1 для безлимита).
2. **Персональное переопределение квоты**:
   - Сущность `LlmUserQuotaOverride`:
     - `user` (`ExtUser`)
     - `monthlyQuotaTokens` (`Integer`)
     - `effectiveFrom` (`Date`, с начала действия)
     - `effectiveTo` (`Date`, дата окончания или `null` для бессрочного)
     - `reason` (`String`)
3. **Текущий период и фактическое использование**:
   - Сущность `LlmChatQuotaPeriod`:
     - `user` (`ExtUser`)
     - `periodStart` (`Date`, первое число текущего месяца)
     - `quotaTokens` (`Integer`)
     - `consumedTokens` (`Integer`)
     - `reservedTokens` (`Integer`)
     - `pendingTokens` (`Integer`)
   - **Остаток токенов**:
     `remaining = quotaTokens - (consumedTokens + reservedTokens + pendingTokens)`.
     Если `quotaTokens == -1` или `Integer.MAX_VALUE` -> `Остаток: Безлимитно`.

## 3. Проектирование UI/UX

### 3.1. Личный дашборд `UserAiDashboard`
В блоке KPI (`kpiPanel`):
- В карточке токенов `tokensCard` (`ai-kpi-card kpi-purple`):
  - Значение: `tokensLabel` -> `Использовано / Остаток` (например: `12.4k / 487.6k`).
  - Подпись: `tokensSubLabel` -> `Лимит: 500.0k токенов (остаток 97.5%)`.
- Дополнительно под карточками отображается аккуратная полоса прогресса квоты месяца с визуальным бейджем статуса (`Норма`, `Внимание >80%`, `Исчерпано 100%`).

### 3.2. Административный дашборд `AdminAiDashboard`
Во вкладке «Пользователи» (`usersTab`):
- Таблица `userSummaryTable` расширяется:
  - Источник данных: все активные пользователи (`ExtUser`, `active = true`), обогащенные данными квот и фактического расхода.
  - Колонки:
    1. `Пользователь` (`userName`)
    2. `Выделено токенов` (`quotaDisplay`) — квота на месяц (с пометкой «Индивидуальная» или «По умолчанию»).
    3. `Использовано токенов` (`consumedTokens`)
    4. `Остаток токенов` (`remainingTokens`) — с цветовым форматированием (зеленый / желтый / красный).
    5. `Число вызовов` (`totalCalls`)
    6. `Расход ($)` (`estimatedCost`)
    7. `Последняя активность` (`lastCallTime`)

### 3.3. Карточка пользователя `ExtUserEditor`
Во вкладке `aiSettingsTab` добавляется карточка `adminAiQuotaCard` (`groupBox` / `vbox stylename="edit-card"`):
- Заголовок: ` msg://msgAdminAiQuotaTitle` («Лимиты и использование корпоративных моделей AI»)
- Сетка полей `edit-form-control`:
  1. `monthlyQuotaTokensField` (`textField`): «Выделено администратором токенов (месячный лимит)»
     - Подсказка: «-1 — безлимит; пусто — значение по умолчанию системы (500 000)».
  2. `consumedTokensField` (`textField`, `editable="false"`): «Использовано в текущем месяце (списано)»
  3. `remainingTokensField` (`textField`, `editable="false"`): «Остаток токенов на сегодня»
  4. `quotaStatusLabel` (`label htmlEnabled="true"`): бейдж статуса расхода лимита сотрудником.
