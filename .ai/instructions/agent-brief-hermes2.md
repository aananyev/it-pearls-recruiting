Твоя роль: разработка фич (ветки, коммиты, PR). Схема: Hermes-1 (CI/CD: проверка PR, merge, deploy, restart, миграции), ты (разработка), Antigravity IDE (второй поток разработки).

1. .cursorrules — секция «РАБОТА АГЕНТОВ (GIT-ПРОТОКОЛ, ОБЯЗАТЕЛЕН)»

3. .ai/coordination-protocol.json — роли и каналы

Git-протокол (не нарушать):
- Работай ТОЛЬКО в своём worktree: git worktree add ../hrm-hermes2 -b agent/<тема> от свежего origin/master. Общую рабочую копию (корень репо) не трогай — она для master и деплоя Hermes-1
- Никаких долгоиграющих незакоммиченных правок: каждый готовый шаг — коммит (русское сообщение по конвенции: type(scope): описание + bullets из фактического diff) + git push в свою ветку
- Перед стартом и после мержа чужого PR: git fetch, обновись от origin/master (merge или rebase), разреши конфликты в СВОЕЙ ветке, беря обе стороны
- Shared-файлы (styles.scss ×7 тем, messages*.properties, build.gradle, docs/README) — конфликтуют часто: резолвишь сам, обе стороны; версию build.gradle не бампаешь вручную — это делает pre-commit hook
- Слияние — только через PR (base=master). PR создавай с описанием: что сделано, как проверено, что ожидаешь от Hermes-1. Метка WAITING_FOR_HERMES = «проверь и задеплой»

Сборка и тесты:
- Прогоны gradle СЕРИАЛИЗУЙ с другими агентами: один gradle-процесс в момент времени (общий кэш, FTS-локи, дубли jar ломают всё). Если видишь чужой gradle — жди или согласуй
- Перед PR обязательно: ./gradlew :app-core:test --tests "<твой контрактный тест>" --tests "com.company.hunttech.core.ScreenViewIntegrityTest" + :app-web:buildScssThemes (если трогал SCSS) + docs (docs/ui/, docs/entities/) по правилам проекта
- НЕ деплой и НЕ рестарт: это зона Hermes-1. Свой runtime (Tomcat/БД) не поднимай без запроса

Коммуникация:
- Задачи от Hermes-1 приходят через .ai/tasks/*.md — читай перед работой
- Отчёты о своей работе клади в .ai/instructions/ (задания) и комментируй PR; ошибки/непонятное — в PR-комментарии
- Асинхронно: не жди ответа в чате — состояние в ветках, PR, файлах .ai/

Язык: вся работа (комментарии, коммиты, доки, отчёты) — на русском, идентификаторы кода — как в репо. Не коммить чужое (незакоммиченные правки других агентов), не переключай ветки в чужом worktree, не stash чужих изменений.

Текущее состояние (на момент старта): в общей копии могут быть незакоммиченные правки других агентов — не трогай их. Свой worktree создай от актуального origin/master.
