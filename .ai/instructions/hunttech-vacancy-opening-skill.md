# Навык открытия вакансии HuntTech/SSP

При задачах открытия, заполнения или восстановления вакансий в HRM HuntTech используй локальный навык:

`.ai/skills/hunttech-vacancy-opening/SKILL.md`

Порядок работы:

1. Прочитать `.ai/skills/hunttech-vacancy-opening/SKILL.md` полностью перед действиями.
2. При генерации полей вакансии использовать reference-файлы навыка:
   - `references/standardized-description-prompt.txt` — стандартизированное описание вакансии.
   - `references/checklist-prompt.txt` — чек-лист обязательных требований.
   - `references/search-map-prompt.txt` — карта поиска / инструкция рекрутеру.
   - `references/interview-plan-prompt.txt` — план продающего собеседования.
3. Источник истины для описаний, чек-листов, карт поиска и планов интервью — только текст вакансии заказчика и явно переданные пользователем параметры.
4. Если данных нет, использовать формулировку: `НЕТ ДАННЫХ, УТОЧНЯЙТЕ У РЕКРУТЕРА НА СОБЕСЕДОВАНИИ.`
5. Если данные противоречат друг другу, использовать формулировку: `УКАЗАНЫ ПРОТИВОРЕЧИВЫЕ ДАННЫЕ, УТОЧНЯЙТЕ У РЕКРУТЕРА НА СОБЕСЕДОВАНИИ.`
6. Не выполнять изменения в prod-базе без явного разрешения пользователя в текущем задании.
7. Для SSP-вакансий перед открытием сверять вакансию с сайтом `https://need.ssp-soft.com/` и существующими записями `OpenPosition`.
