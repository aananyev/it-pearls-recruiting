## Баг, найденный при проверке после мержа

`DevelopmentException: Unable to find an instance of type 'interface ...Button' named 'rescanResume'`

но в Java осталась `@Inject Button rescanResume` + `rescanResume::focus`.

и `skillActionsPopupButton::focus` в navigateSkillActions().
