## 1. Дефект 1: CompanyEdit (Карточка компании)

### Экран
- XML: `modules/web/src/com/company/hunttech/web/screens/company/company-edit.xml`
- Экран в системе: `Компании редактирование` (`hunttech_Company.edit`)
- Скриншоты фиксации:
  - Основной экран: `evidence/2026-09-05-company-edit-screen.png`
  - Пустая вкладка: `evidence/2026-09-05-company-edit-tab2.png`

### Симптомы дефекта
1. **Срезание нижнего подвала действий (Actions Footer)**:
   - Кнопки «ОК» и «Отмена» в нижней панели `actionsPane` обрезаются нижней границей экрана браузера (видна только верхняя треть кнопок).
   - Причина: рабочая область `edit-workspace` / `edit-workspace-content` не ограничивает высоту контента под вьюпорт, в результате чего футер выталкивается за пределы видимой области без возможности корректного скролла к нему.
2. **Схлопывание содержимого вкладок (0 height / Blank Tab Content)**:
   - Во вкладке «Информация о компании» отображаются только верхние две плашки, а вся основная рабочая область под ними представляет собой пустое серое поле.
   - Во вкладках «Официальные реквизиты», «Описание компании», «Департамент» содержимое полностью отсутствует/схлопнуто (пустая серая область без полей).
   - Причина: конфликт высоты `height="100%"` / `v-scrollbox` / `company-tab-scroll` внутри вкладок Vaadin TabSheet при отключенном абсолютном позиционировании или некорректном расчете flex/grid высоты родителя.

## 2. Дефект 2: ExtSettingsWindow (Настройки приложения / ИИ-профиль)

### Экран
- XML: `modules/web/src/com/company/hunttech/web/screens/settings/ExtSettingsWindow.java` / `ext-settings-window.xml`
- Экран в системе: `Настройки` (`ExtSettingsWindow` / `appSettings`)
- Скриншот фиксации: `evidence/2026-09-05-ext-settings-active.png`

### Симптомы дефекта
1. **Наложение кнопок тулбара (Horizontal Overlap)**:
   - В тулбаре раздела «Профессиональный ИИ-профиль» (вкладка «AI» / «Обо мне»):
     Кнопка `danger` «Очистить ИИ-профиль» физически накладывается поверх кнопки `primary` «Показать передаваемые данные», перекрывая её правую часть.
   - Причина: абсолютное позиционирование или `float: right` без отступа, либо фиксированная ширина контейнера действий `user-ai-profile-toolbar-actions` при длинных текстах кнопок.
2. **Наложение метки на поле ввода (Field Label & Input Overlap)**:
   - В первой строке карточки «Профессиональный профиль»:
     Метка поля «Функциональная роль» накладывается непосредственно поверх поля ввода «Текущая должность» (значение «Директор»).
   - Причина: некорректная сетка/позиционирование строк формы (FormLayout / GridLayout) в первой группе полей.
