# Спецификация: Отображение Markdown-разметки в диалоге LLM-chat

**Дата**: 2026-09-09  
**Роль**: Аналитик  
**Статус**: Утверждено к реализации  
**Целевой модуль**: `modules/web` (HRM HuntTech / CUBA Platform 7.3)

---

## 1. Контекст и бизнес-цель

Пользователи HRM взаимодействуют с языковыми моделями через встроенный плавающий диалог `LlmChatScreen`. Языковые модели возвращают структурированные ответы с использованием Markdown:
- Списки кандидатов, вакансий и требований (`-`, `*`, `1.`);
- Блоки кода и SQL/JSON (` ``` `);
- Выделение ключевых сущностей жирным (`**`) и курсивом (`*`);
- Заголовки секций (`#`, `##`, `###`);
- Табличные сравнения (`|`);
- Ссылки и цитаты.

В текущей версии `llm-chat-screen.xml` используется стандартный CUBA `<textArea id="historyArea" editable="false"/>`, который выводит Markdown как сырой текст без оформления, что снижает читаемость и удобство восприятия.

**Задача**: Обеспечить полноценный визуальный рендеринг Markdown-текста в окне `LlmChatScreen`, сохранив потоковую передачу данных (streaming) и интеграцию со стилями всех 7 SCSS-тем системы.

---

## 2. Архитектурные требования

1. **CUBA UI Контейнер**:
   - Замена `<textArea id="historyArea">` на вертикальный контейнер `<scrollBox id="historyScrollBox">` с элементом `<label id="historyLabel" htmlEnabled="true">`.
   - Поддержка `htmlEnabled="true"` для рендеринга безопасного HTML.
   - Автоматическая прокрутка к последнему сообщению при каждом обновлении (включая стриминг токенов) через Vaadin Panel:
     `panel.setScrollTop(Integer.MAX_VALUE / 2)`.

2. **Безопасность (XSS Protection)**:
   - Исходный текст пользователя и ИИ обязательно санитизируется (экранирование `<`, `>`, `&`, `"`) до применения правил Markdown, предотвращая XSS-атаки и нарушение структуры DOM интерфейса CUBA.
   - Ссылки валидируются на безопасные протоколы (`http`, `https`, `mailto`) с атрибутами `target="_blank" rel="noopener noreferrer"`.

3. **Спецификация MarkdownRenderer (Java Pure)**:
   - Без привлечения внешних неустановленных сторонних библиотек (автономный надёжный парсер в `com.company.hunttech.web.screens.llmchat.MarkdownRenderer`).
   - Поддерживаемые конструкции:
     - Заголовки: `# H1`, `## H2`, `### H3`, `#### H4` -> `<h3 class="llm-md-h3">`..`<h6 class="llm-md-h6">`.
     - Форматирование: `**жирный**`, `*курсив*`, `` `инлайн-код` ``.
     - Блоки кода с указанием языка: ```` ```lang ... ``` ```` -> `<pre class="llm-md-pre"><code class="llm-md-code">`.
     - Маркированные и нумерованные списки с правильной вложенностью и отступами.
     - Блоки цитат (`>`) -> `<blockquote class="llm-md-quote">`.
     - Таблицы Markdown (`| a | b |`) -> `<table class="llm-md-table">`.
     - Разделители (`---`, `***`).
     - Ссылки `[текст](url)`.
     - Переносы строк и параграфы.

4. **Дизайн и UI/UX реплик**:
   - Сообщения пользователя: компактная реплика с выравниванием / индикатором `Вы`, мягкий фоновый тон.
   - Сообщения ИИ: карточка с бейджем `ИИ`, структурированная типографика Markdown.
   - Временной стриминг liveText: визуальный индикатор генерации ответа.

5. **Синхронизация стилей**:
   - Все стилевые правила для `.llm-chat-history-scroll`, `.llm-chat-history-content`, `.llm-chat-msg-*`, `.llm-md-*` добавляются в `chat-style.scss` и синхронизируются байт-в-байт во всех 7 темах:
     `hover`, `halo`, `helium`, `havana`, `hunttech-modern`, `hunttech-modern-light`, `hunttech-modern-dark`.
