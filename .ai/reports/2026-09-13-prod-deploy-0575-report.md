## 1. Состав выкаченных изменений релиза 0.575

### 1.1. Функция «Умная загрузка» (заведение карточки кандидата)
1. **Строгая дедупликация кандидатов**:
   - Двухуровневый алгоритм в `SmartCvIngestServiceBean`: поиск по точным номерам и шаблонам с масками `%p1%p2%p3%p4%` (`+7 (999) 111-22-33`, `8-999-111-2233` и др.), fallback на `mobilePhone`, Telegram (с `@` и без него), ФИО с перестановкой.
   - В мастере `SmartCvUploadScreen`: предупреждающий блок `duplicateBox` с вопросом рекрутеру. Основное действие по умолчанию (primary) — **«Не дублировать (привязать резюме к кандидату)»**. Создание дубликата требует явного модального подтверждения через диалог.
2. **Очистка названий компаний**:
   - Кириллические формы собственности (ООО, ПАО, ЗАО, АО, ИП, НКО, Ltd, LLC, Inc, Corp) корректно отсекаются с флагом `(?U)`.
3. **Отказоустойчивость извлечения текста**:
   - Автоматический fallback на прямой разбор `word/document.xml` из zip-архива DOCX с защитой от zip bomb (лимит размера).
   - Распознавание RTF-документов HeadHunter с расширением `.doc` по сигнатуре `{\rtf` и разбор через `RTFEditorKit`.
   - Поддержка Apple Pages через векторный `Preview.pdf`.
4. **Калиброванный системный промпт v3 (`CV_SMART_PARSE_JSON`)**:
   - Применена миграция системных данных: строгое правило `null` вместо `'Не указано'` / `'Нет'`, атомарные hard skills без софт-скиллов, нормализация контактов (+7...), защита от галлюцинаций дат рождения.

### 1.2. LLM-чат и Hermes Agent
1. **Полноценная интеграция с Hermes Agent**:
   - Подключение к контейнеру Hermes (`hrm-viewer`) с доступом к базе данных в режиме чтения.
   - Автоматический fallback цепочки моделей: пользовательская настройка -> административная -> дефолт контейнера.
2. **Удаление технических ID сущностей**:
   - Из вывода Hermes полностью исключены кракозябры и технические ID вида `"8a0f5f9c-6a32-4e6a-a2c9-672870000001"`, префиксы `ID:`, скобки `(ID: ...)`.
   - В системный промпт Hermes добавлено строгое правило запрета вывода технических ID.
   - `HrmEntityNameResolver` расширен: кроме вакансий, кандидатов, резюме и компаний, автоматически преобразует в читаемые ссылки должности (`Position`), навыки (`SkillTree`), проекты (`Project`), пользователей (`ExtUser`) и города (`City`).
3. **Контекст диалога**:
   - Поддержка непрерывного контекста до 10 000 токенов с автоматическим сбросом при превышении квоты.
