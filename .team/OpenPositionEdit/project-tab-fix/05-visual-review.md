## 0. Метод и ограничения
- OCR: Vision (ru/en, accurate) `/tmp/ocr_render.swift`; координаты = верхний левый угол bbox текста, погрешность ±10–30px.
- Структура: детекция рамок/границ по пикселям (PIL), сверка цветов тем по пикселям.
- **Приоритет доказательств: CDP DOM-факты (точные runtime-замеры того же сеанса) > OCR/пиксели** (OCR способен
  сливать соседние границы полей и давать сбои координат мелких элементов — зафиксировано: «Генерировать» в разных
  прогонах x≈689–1148, тогда как DOM x=1776).
- Deploy подтверждён: sidebar присутствует на скриншотах (есть только в рабочем дереве XML → задеплоен полный working-tree);
  скомпилированный CSS в deploy содержит `.open-position-editor-cards-row{display:flex!important;flex-direction:column!important;…gap:14px;width:100%!important;margin:0 0 12px}` (6 вхождений cards-row) — B/D-правка живая.
