# Бизнес-влияние отсутствующих файлов

## Затронутые области

По найденным ссылкам затронуты:

- резюме кандидатов;
- оригинальные файлы резюме;
- вложения и дополнительные файлы;
- результаты импортов;
- очередь полнотекстового поиска CUBA.

## Активные риски

1. Пользователь открывает карточку кандидата, но файл резюме недоступен.
2. История кандидата формально сохранена в базе, но документальная часть неполная.
3. Файлы, участвовавшие в импортах, невозможно повторно проверить.
4. Полнотекстовый поиск может пытаться индексировать отсутствующие `sys_file`.
5. Поддержка не сможет отличить ошибку миграции от исторически потерянного файла без отдельного решения по каждой группе.

## Что нельзя делать автоматически

- Удалять строки `sys_file`.
- Удалять или занулять ссылки на файлы.
- Создавать пустые файлы-заглушки.
- Отключать ошибки загрузки файлов в приложении.
- Считать отсутствие файла допустимым только потому, что запись старая.

## Требуемое бизнес-решение

Владелец HRM должен подтвердить один из вариантов:

- найти и восстановить отсутствующие файлы из внешних архивов;
- признать часть файлов исторически утраченными и документировать это;
- отложить переключение приложения до восстановления критичных документов.
