# Журнал решений по отсутствующим файлам

Все решения по отсутствующим файлам должны быть явно подтверждены владельцем данных до запуска этапа 3.

| Decision ID | Scope | Count | Current status | Required decision |
|---|---|---:|---|---|
| `MF-001` | `E_ACTIVE_LINKED_FILE_MISSING` | 499 | Open | Восстановить из внешнего источника или письменно признать утрату. |
| `MF-002` | `D_ONLY_SOFT_DELETED_OR_ARCHIVE_LINKS` | 2 | Open | Подтвердить архивную политику и допустимость отсутствия. |
| `MF-003` | `C_ORPHAN_SYS_FILE_METADATA` | 132 | Open | Подтвердить, что автоудаление запрещено и записи остаются как metadata issue. |
| `MF-004` | `sys_fts_queue` references | 178 | Open | Решить порядок восстановления или переиндексации после решения по файлам. |

## Правило

Отсутствие ответа считается запретом перехода к этапу 3.
