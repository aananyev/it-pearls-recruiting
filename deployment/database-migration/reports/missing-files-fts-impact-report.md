# Влияние на полнотекстовый поиск

## Найденный факт

В `public.sys_fts_queue.entity_id` найдено 178 ссылок на UUID из списка отсутствующих файлов.

## Интерпретация

`sys_fts_queue` хранит очередь обработки полнотекстового поиска. Ссылка на отсутствующий `sys_file` не доказывает потерю бизнес-сущности сама по себе, но показывает, что CUBA может попытаться обработать отсутствующий файл при индексации.

## Риски

- ошибки индексации после запуска приложения;
- повторное попадание проблемных записей в очередь;
- шум в логах приложения;
- неполные результаты поиска по документам.

## Решение

До этапа 3 нужно отдельно решить, будут ли файлы восстановлены. Очистка `sys_fts_queue` без решения по самим файлам запрещена, потому что это маскирует проблему, но не восстанавливает данные.
