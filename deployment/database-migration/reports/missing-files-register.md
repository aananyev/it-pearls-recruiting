# Реестр отсутствующих файлов

Основной обезличенный CSV-реестр:

`deployment/database-migration/reports/missing-files-register.csv`

Реестр содержит 633 строки и не содержит исходные имена файлов или персональные данные. Для контроля вместо имени файла сохранены:

- UUID `sys_file`;
- ожидаемый относительный путь вида `YYYY/MM/DD/<uuid>.<ext>`;
- расширение;
- размер;
- MD5 от имени файла;
- длина имени файла;
- количество ссылок;
- список колонок-ссылок;
- классификация;
- рекомендуемое действие;
- признак блокировки этапа 3.

## Классы

| Класс | Количество | Значение |
|---|---:|---|
| `E_ACTIVE_LINKED_FILE_MISSING` | 499 | Файл отсутствует, но на него есть активные ссылки. Блокер. |
| `D_ONLY_SOFT_DELETED_OR_ARCHIVE_LINKS` | 2 | Есть только архивные или soft-deleted ссылки. Требуется решение владельца данных. |
| `C_ORPHAN_SYS_FILE_METADATA` | 132 | Запись `sys_file` не имеет найденных ссылок. Автоудаление запрещено. |
| `A_RECOVERABLE_SOURCE_FOUND` | 0 | Источник восстановления найден. |

## Решение

Все 633 записи остаются нерешёнными до ручного бизнес-решения. Удаление строк `sys_file`, зануление ссылок и создание фиктивных файлов запрещены.
