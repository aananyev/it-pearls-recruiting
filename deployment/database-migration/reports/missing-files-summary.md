# Краткое резюме missing files

На этапе 2.1 проверен блокер file storage после миграции `itpearls -> hunttech`.

## Факты

- `sys_file` содержит 13460 записей.
- Физически найдено 12827 ожидаемых файлов.
- Не найдено 633 файла.
- Из них 499 имеют активные ссылки в данных HRM.
- Источник восстановления среди активного file storage и найденного backup fileStorage не найден.

## Распределение по годам

Основной массив отсутствующих файлов относится к 2019-2021 годам. Самая крупная группа: PDF-файлы 2020 года.

## Решение по этапу

Этап 3 нельзя начинать. Перед продолжением нужно либо найти внешний источник этих файлов, либо получить письменное бизнес-решение, какие записи допустимо оставить как отсутствующие.
