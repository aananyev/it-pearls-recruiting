# Runbook: откат восстановления файлов

## Назначение

Откатить только те файлы, которые были восстановлены отдельной утверждённой процедурой. Этот runbook не предназначен для удаления исторических production-файлов.

## Порядок

1. Проверить manifest восстановления.
2. Проверить список файлов, которые были скопированы процедурой восстановления.
3. Запустить `recovery/rollback-restored-files.sh` в dry-run.
4. Сравнить план удаления с manifest.
5. Получить отдельное подтверждение DBA.
6. Выполнить rollback только с `ALLOW_REMOVE_RESTORED_FILES=yes`.
7. Повторить проверку file storage.

## Запреты

- Не удалять файлы, которых нет в manifest восстановления.
- Не удалять каталоги year/month/day целиком.
- Не менять базу данных.
