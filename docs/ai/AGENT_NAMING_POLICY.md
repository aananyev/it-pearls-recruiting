# Правило именования субагентов

## Назначение

Все субагенты HRM HuntTech в заданиях, коммуникации, handoff, приемочных отчетах и документации идентифицируются строго по должности/роли.

## Разрешенные обозначения

- Аналитик
- Автоматизированный тестировщик
- Руководитель проектов
- UI/UX-дизайнер
- Frontend-разработчик
- Java Backend-разработчик
- Оператор HRM

## Запреты

Нельзя использовать личные имена, случайные nicknames, псевдонимы или кодовые имена субагентов. Основной агент также указывает в отчетах только должности, даже если платформа отображает технический nickname.

## Ограничение платформы

Генерируемый платформой nickname может отображаться в техническом интерфейсе и не всегда управляется промптом или API запуска субагента. Такой nickname не является рабочим именем и не переносится в проектную документацию.

## Контроль

Перед приемкой каждого этапа основной агент проверяет, что в отчете и handoff указаны должности, а не nicknames. Нарушение исправляется до публикации отчета.
