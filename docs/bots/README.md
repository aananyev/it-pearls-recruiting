# Боты HRM HuntTech

Раздел описывает служебных Telegram-ботов HRM HuntTech: назначение, сценарии, интеграции, хранилища, правила подтверждения и точки связи с сущностями HRM HuntTech.

## Документы

| Документ | Краткое описание |
| --- | --- |
| [AccountingDocumentsHermesBot.md](AccountingDocumentsHermesBot.md) | Внешний бухгалтерский Telegram-бот, работающий в Hermes и использующий AI API Hermes |
| [AccountingDocumentsTelegramBot.md](AccountingDocumentsTelegramBot.md) | Telegram-бот бухгалтерской первички и чеков авансового отчета |
| [AccountingDocumentsTelegramBot_MVP_Plan.md](AccountingDocumentsTelegramBot_MVP_Plan.md) | MVP-план минимально необходимой реализации бухгалтерского Telegram-бота |

## Правила раздела

- каждый бот описывается отдельным документом;
- документ должен начинаться с бизнес-контекста: назначение, UI/Telegram-навигация, краткое поведение;
- внешние системы, расписания, папки и статусы фиксируются явно;
- если бот использует сущности HRM HuntTech, документ должен указывать, какие справочники переиспользуются и какие новые сущности требуются;
- история изменений ведется новой строкой сверху.
