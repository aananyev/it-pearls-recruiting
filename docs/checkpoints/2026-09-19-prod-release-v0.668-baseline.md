## 1. Зафиксированное состояние кодовой базы

Настоящий коммит (`21219712b`) принят в качестве единой стабильной отправной точки для всех дальнейших этапов разработки в проекте HRM HuntTech.

### 1.1. Реализованный и задеплоенный функционал:
1. **Этап 3: «Workflow рекрутера после AI-подбора кандидатов на вакансию»**:
   - Диалог подбора вакансий для кандидата (`CandidateVacancyMatchScreen`) в модальном виде с оптимизированной компоновкой действий («Взять в работу», «Взаимодействие», «Предложение (AI)», «Взять выбранных», «Отложить», «Не подходит»).
   - Использование только открытых вакансий (`openClose != true`).
   - Аудит результатов подбора в таблицах `HUNTTECH_VACANCY_CANDIDATE_MATCH_RUN` и `HUNTTECH_VACANCY_CANDIDATE_MATCH_FEEDBACK`.
   - AI-функция умной генерации персонализированного предложения кандидату (`CANDIDATE_VACANCY_OUTREACH_DRAFT`).
2. **Фоновое AI-обогащение навыков кандидатов**:
   - Сервис `CandidateSkillEnrichmentService` и таблица `HUNTTECH_CANDIDATE_CV_SKILL_ANALYSIS`.
   - Функция `SKILLS_EXTRACT_BACKGROUND` с политикой `FREE_ONLY`.
3. **Главное меню платформы**:
   - Устаревший пункт «Открытые вакансии» скрыт, «Реестр открытых вакансий» переименован в «Открытые вакансии».
   - Устаревший пункт «Кандидаты» скрыт, «Реестр кандидатов» переименован в «Кандидаты».
4. **Дашборд контроля AI-функций**:
   - Устранена ошибка JPQL-запроса `functionCode` в `UserAiDashboard`.
   - Актуализированы шлюзы моделей OpenRouter (`nemotron-3-ultra-550b`) как основной бесплатный fallback.
