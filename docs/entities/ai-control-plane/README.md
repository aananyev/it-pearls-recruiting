# AI Control Plane — сущности HRM HuntTech

Профильный каталог сущностей централизованного управления AI.

| Сущность | Документ | Назначение |
|---|---|---|
| `AiFunctionConfiguration` | [../ai-function-configuration/AiFunctionConfiguration.md](../ai-function-configuration/AiFunctionConfiguration.md) | Бизнес-функция, prompt, capability и routing policy |
| `AdminAiConfiguration` | [../admin-ai-configuration/AdminAiConfiguration.md](../admin-ai-configuration/AdminAiConfiguration.md) | Защищённое корпоративное AI-подключение |
| `UserAiFunctionOverride` | [../user-ai-function-override/UserAiFunctionOverride.md](../user-ai-function-override/UserAiFunctionOverride.md) | Персональное замещение подключения для одной функции |

Существующая `UserAiConfiguration` остаётся персональным credential пользователя и не переименовывается.
