# JobCandidate

`JobCandidate` (`hunttech_JobCandidate`, `HUNTTECH_JOB_CANDIDATE`) хранит карточку кандидата.

Связь с текущей компанией хранится в атрибуте `currentCompany`, колонка `CURRENT_COMPANY_ID`. Это `ManyToOne`-ссылка на `Company`, используемая как текущее место работы кандидата.

В редакторе кандидата поле компании является обязательным на UI. Сохранение связи происходит вместе с сохранением кандидата; сохранение новой компании из дочернего редактора не выполняет commit кандидата автоматически.

Схема БД для этой задачи не менялась.
