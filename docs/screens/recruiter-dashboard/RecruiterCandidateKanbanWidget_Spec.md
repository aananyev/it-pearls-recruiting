- **ID контроллера**: `hunttech_RecruiterCandidateKanbanWidget`

- **Java-контроллер**: `RecruiterCandidateKanbanWidget.java`
- **Дашборд**: `recruiter-kanban-dashboard.xml` (`recruiter-kanban-dashboard.json`)
- **Статус**: актуален (2026-09-24, доработки по эргономике и скроллингу)

## 1. Назначение и бизнес-логика

Виджет «Кандидаты в работе (Kanban)» предназначен для визуального оперативного управления воронкой подбора кандидатов конкретным рекрутером. Виджет агрегирует активные взаимодействия (`IteractionList`), группирует их по этапам процесса найма и выводит в виде интерактивной доски с карточками кандидатов.

### Ключевая бизнес-логика:
1. **Определение активного рекрутера**:
   - Используется `userSession.getCurrentOrSubstitutedUser()`, что позволяет руководителю/администратору работать под учетной записью замещаемого рекрутера (например, `eliberman`) с корректным отображением её личных кейсов.
   - В селекторе рекрутера доступно быстрое переключение между сотрудниками.
2. **Фильтрация по периоду**:
   - Переключатель периода (`periodRadioGroup`): **30 дн.**, **90 дн.** (по умолчанию), **Всё время**.
   - По умолчанию для рекрутера Либерман отображаются 233 активных кейса за последние 90 дней.
3. **Безопасная JPQL-выборка без потери кейсов без вакансий**:
   - В подзапросе поиска последней активности учитывается `((e.vacancy is null and x.vacancy is null) or x.vacancy = e.vacancy)`, что гарантирует включение кандидатов, не привязанных к конкретной вакансии.
4. **Текстовая фильтрация**:
   - Текстовое поле поиска (`searchField`) позволяет налету фильтровать карточки по ФИО кандидата и наименованию вакансии.
5. **Маппинг этапов воронки (`RecruiterDashboardStage`)**:
   - `NEW` — Новые кандидаты;
   - `RECRUITER_INTERVIEW` — Интервью с рекрутером;
   - `CLIENT_PRESENTATION` — Передано заказчику;
   - `CLIENT_INTERVIEW` — Интервью с заказчиком;
   - `OFFER` — Оффер / Выход;
   - `OUTCOME` — Отказ / Архив;
   - `RESERVE` — Кадровый резерв.

## 2. Экранная компоновка и визуальная эргономика

Компоновка виджета спроектирована по стандарту Edit/Browse-форм HRM HuntTech с компактным вертикальным ритмом и отсутствием лишнего свободного пространства:

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ [Заголовок доски + счетчик]                     [Рекрутер] [30/90/Всё] [Поиск] [⟳]     │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ [KPI: Новые: 12] [KPI: Интервью: 34] [KPI: Заказчик: 18] [KPI: Оффер: 5] ...          │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ ┌────────────────┐ ┌────────────────┐ ┌────────────────┐ ┌────────────────┐ ...        │
│ │ ЭТАП: НОВЫЕ (12)│ │ ЭТАП: ИНТЕРВЬЮ │ │ ЭТАП: ЗАКАЗЧИК │ │ ЭТАП: ОФФЕР    │           │

│ │ [Карточка N]   │ │ [Карточка N]   │ │ [Карточка N]   │ │ [Карточка N]   │ колонок    │
│ └────────────────┘ └────────────────┘ └────────────────┘ └────────────────┘            │
│ ◀─────────────────────────── Горизонтальный скролл ──────────────────────────▶         │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

### 1. Верхний командный тулбар (`headerBar`):
- **Слева**: `headerBox` (`width="AUTO"`, `stylename="recruiter-kanban-title-box"`):
  - Заголовок: `Кандидаты в работе (Kanban)` (`font-size: 16px`, `font-weight: 700`, компактный отступ 2px).
  - Подзаголовок: `periodLabel` (`font-size: 11.5px`, приглушенный цвет) с периодом и общим количеством кейсов.
- **Справа**: `filterControlsBox` (`alignment="MIDDLE_RIGHT"`, `gap: 8px`):
  - `recruiterLookupField` (`width="220px"`): выпадающий список активных пользователей.
  - `periodRadioGroup` (`stylename="recruiter-kanban-period-radio"`): эргономичные опции `30 дн.`, `90 дн.`, `Всё время`.
  - `searchField` (`width="180px"`): текстовый поиск кандидата.
  - `refreshBtn` (`stylename="recruiter-kanban-refresh-btn"`): кнопка обновления с иконкой `REFRESH` и всплывающей подсказкой.

### 2. Панель KPI-индикаторов (`kpiBar`):
- Компактные карточки (`padding: 6px 12px`, `min-width: 120px`, `border-left: 3px solid accent`).
- Значения: `font-size: 18px / 700`, цветные акценты этапов (синий, фиолетовый, зелёный).
- Подписи: `font-size: 11px`, компактный межстрочный интервал.

### 3. Механизм двойного скроллинга (Horizontal & Vertical):
- **Внешний контейнер (`kanbanScrollBox`)**:
  - `scrollBarPolicy="BOTH"`, `orientation="both"`.
  - Обеспечивает горизонтальное перемещение по колонкам воронки при любой ширине экрана.
  - При малой высоте экрана или большого количества карточек обеспечивает вертикальную прокрутку всей доски без обрезания карточек.
- **Колонки канбана (`recruiter-kanban-column`)**:
  - Фиксированная ширина `300px` (`min-width: 290px`, `flex: 0 0 300px`).
  - Цветной индикатор этапа на верхней границе (`border-top: 3px solid`).
  - Заголовок этапа и бейдж-счётчик кандидатов.
- **Внутренний вертикальный скроллер колонки (`recruiter-kanban-column-scroll`)**:
  - `ScrollBoxLayout` с `setScrollBarPolicy(ScrollBoxLayout.ScrollBarPolicy.VERTICAL)`.
  - Фиксированная высота `540px` (`max-height: 560px`), `overflow-y: auto`.
  - Тонкий стилизованный скроллбар (`scrollbar-width: thin`), гарантирующий видимость всех нижних карточек.

## 3. Карточка кандидата (Презентационный контракт «Эскиз 3»)

Карточка построена на базе `VBoxLayout` с классом `recruiter-kanban-card`:
1. **Аватар и идентификация**:
   - Круглый фото-аватар `WebOvaFallbackImage` (42×42px) с fallback-изображением или фото из `JobCandidate.fileImageFace`.
   - ФИО кандидата как `LinkButton` с открытием редактора `JobCandidate`.
   - Бейдж должности `recruiter-kanban-position-badge` (11px, скругление 3px).
2. **Инфо-строка (Рейтинг ★ + Локация 📍)**:
   - Золотая звезда рейтинга `★ 4.x` (`color: #f59e0b`).
   - Город проживания `📍 Город` (`color: #64748b`).
3. **Вакансия**:
   - `💼 Название вакансии` (`recruiter-kanban-vacancy`, полужирный шрифт, 12px).
4. **Статус взаимодействия и дата**:
   - Текущий статус воронки (`recruiter-kanban-interaction`).
   - Дата взаимодействия (`dd.MM.yyyy`, приглушенный шрифт).
5. **Действие**:
   - Кнопка **«Карточка профиля»** (`small primary recruiter-kanban-card-btn`) с переходом в экран кандидата.

## 4. Паритет стилей и тем оформления

Стили виджета изолированы под селектором `.recruiter-dashboard-root` в файле `recruiter-dashboard-shared-styles.scss` и идентичны байт-в-байт во всех 7 темах оформления:
- `hunttech-modern`
- `hunttech-modern-dark`
- `hunttech-modern-light`
- `halo`
- `havana`
- `helium`
- `hover`

Целостность стилей и байтовое совпадение во всех темах валидируются автоматизированным тестом `RecruiterDashboardsContractTest`.
