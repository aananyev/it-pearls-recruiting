# ExtSettingsWindowMainBackground — настройка фона главного экрана

> Screen ID: `settings`.  
> Контроллер: `ExtSettingsWindowMainBackground`.  
> Базовая цепочка: `ExtSettingsWindowInterfaceLayout` → `ExtSettingsWindowEmailNavigation` → `ExtSettingsWindow`.

## Назначение и бизнес-смысл (What & Why)

Расширение позволяет выбрать персональное изображение либо системный каталог активной темы. Оно также задаёт однозначное поведение выхода: «ОК» сохраняет и закрывает без повторного вопроса, «Отмена» предлагает остаться либо выйти без сохранения.

## UI Context & Navigation

В левой панели вкладки «Интерфейс» после существующих четырёх пунктов добавлена кнопка «Фон главного экрана». Нажатие активирует пункт и переводит фокус к `mainScreenBackgroundUpload`, прокручивая правую область до карточки фона.

## Behavior Summary

- открытие → загружается текущий `UserSettings.fileImageFace`;
- выбор пункта слева → фокус на upload;
- загрузка PNG/JPG/JPEG/WEBP → файл маркируется `hrm-main-background-`;
- «Использовать системные фоны» → ссылка очищается в редактируемом datasource;
- «ОК» → выполняется действующая commit-цепочка → повторная unsaved-проверка подавляется только на время успешного закрытия;
- «Отмена» → диалог «Остаться в экране или выйти без сохранения?»;
- «Остаться» → окно остаётся открытым;
- «Выйти без сохранения» → `closeWithDiscard()`;
- entity, БД, Liquibase и views не меняются.

Component ID нового пункта: `interfaceSettingsBackgroundNav`. Active state синхронизируется с существующими пунктами.

## Контракт кнопок

### ОК

Флаг `successfulCommitClosing` влияет только на `hasUnsavedChanges()` во время `super.commit()`. Валидация, `CommitContext`, тема, язык, режим окна, часовой пояс, стартовый экран, email и AI-профиль сохраняются прежней логикой.

### Отмена

Доступны только действия `Остаться` и `Выйти без сохранения`. Второе использует штатный CUBA `closeWithDiscard()`.

## Проверки Hermes

Проверить навигацию, единичный active state, сохранение через «ОК» без диалога, оба действия «Отмена», отсутствие сохранения при discard, фон после повторного входа и отсутствие регрессии вкладок «Обо мне», email и AI.
