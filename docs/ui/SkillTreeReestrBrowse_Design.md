## 3. Состояния

- **Пустой выбор**: аватар-fallback, «Выберите компетенцию», прочерки, обе кнопки сайдбара disabled.
- **Корневой узел**: уровень 3 показывает «Корневая компетенция» (вместо «Родитель: …»).
- **Без логотипа**: `applyFallback()` (ovaFallbackImage) — без битых картинок.
- **Нет детей**: плейсхолдер-чип «Дочерних навыков нет» (серый 11px).
- **Wiki пуст**: «—»; при наличии — ссылка 📖 Открыть Wiki (target=_blank, HTML-экранированный href).

## 4. Адаптивность

- ≤1240px: кнопки тулбара переносятся flex-wrap (классы `candidate-filter-bar` тем).
- ≤900px: сайдбар остаётся 312px (скролл), рабочая область сжимается; колонки Wiki/Парсинг скрываются таблицей (resizable).
- Тёмная тема (hunttech-modern-dark): все фоны чипов/секций — через общие контрактные классы, инвертируются mixin-ами тем; новых правил не введено.

## 5. Безопасность вывода

Все пользовательские данные (название, комментарий, wiki, стиль) проходят
`escapeHtml()` перед попаданием в htmlEnabled-label — защита от HTML-инъекций
из данных справочника.
