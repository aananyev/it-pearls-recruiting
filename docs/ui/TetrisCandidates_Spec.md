# Спецификация экранного модуля «Тетрис с кандидатами» (TetrisCandidates)

## 1. Назначение и бизнес-цели модуля

Экран **«Тетрис с кандидатами»** (`hunttech_TetrisCandidates`) входит в группу меню «Мастера HRM» (`application-hrmasters`) и представляет собой специализированное рабочее пространство рекрутера/ресерчера для интерактивного сопоставления пула активных кандидатов с открытыми вакансиями компании и быстрой фиксации взаимодействий.

### Ключевые бизнес-задачи:
1. **Пакетное сопоставление (Тетрис-маппинг)**:
   - В едином горизонтально-вертикальном представлении рекрутер видит каждого кандидата и матрицу всех доступных позиций (слотов).
   - Слоты позиций окрашены в соответствии с текущей фазой взаимодействия.
2. **Оперативная коммуникация (1-click Action)**:
   - Отправка персонального предложения по шаблону вакансии через встроенный мастер `InternalEmailer`.
   - Мгновенный переход в карточку редактирования кандидата (`JobCandidateEdit`).
   - Исключение кандидата из рассмотрения по позиции или общий возврат.
3. **Фильтрация и приоритизация**:
   - Фильтр по типам позиций и готовности к предложениям.
   - Переключение детального и компактного режимов отображения.
   - Сворачиваемый блок исключенных кандидатов с историей.

## 2. Архитектура и компоненты

### 2.1. Экранный дескриптор `tetris-candidates.xml`
- **Контроллер**: `com.company.hunttech.web.screens.fragments.tetriscandidates.TetrisCandidates` (`hunttech_TetrisCandidates`).
- **Заголовочная панель**:
  - Карточка с иконкой `TH_LARGE`, названием «Тетрис с кандидатами» и описанием рабочего процесса.
- **Рабочая область**:
  - Встроенный persistent dashboard `tetrisCandidatesDashboard` с кодом `tetris-candidates-dashboard` и fallback на `com/company/hunttech/web/screens/mainscreen/dashboards/tetris-candidates-dashboard.json`.

### 2.2. Виджет `MyActiveCandidatesDashboard`
- **Контроллер**: `com.company.hunttech.web.widgets.candidates.MyActiveCandidatesDashboard` (`hunttech_MyActiveCandidatesDashboard`).
- **Параметры**:
  - `detailMode = true`: отображение расширенных метаданных кандидата (город, грейд, резюме).
  - `simpleMode = false`: полный интерактивный режим с матрицей вакансий.

## 3. Цветовая модель слотов тетриса

| Статус слота | CSS Класс | Назначение |
|---|---|---|
| **Opportunity** (Доступно) | `text-block-gradient-green` / `tetris-slot-opportunity` | Можно предложить кандидата на открытую вакансию |
| **In Progress** (В работе) | `text-block-gradient-yellow` / `tetris-slot-in-progress` | Кандидат находится на этапе рассмотрения/собеседования |
| **Closed** (Завершено) | `text-block-gradient-red` / `tetris-slot-closed` | Взаимодействие завершено, оффер принят либо отказ |

## 4. Требования к UI/UX и адаптивности

1. **Единый стиль 7 тем**:
   - Стили модуля вынесены в `tetris-candidates.scss` и подключены во все 7 тем (`halo`, `havana`, `helium`, `hover`, `hunttech-modern`, `hunttech-modern-light`, `hunttech-modern-dark`).
2. **Карточная компоновка**:
   - Каждая строка кандидата оформляется как карточка с мягким скруглением углов (8px), тонким бордером и паддингом 12px.
   - Горизонтальный скролл слотов вакансий не ломает общую высоту экрана.
3. **Data View Integrity**:
   - Все сущности (`JobCandidate`, `IteractionList`, `OpenPosition`) загружаются через полные view без lazy-инициализации в UI-потоке.
